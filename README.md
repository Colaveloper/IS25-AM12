# Project Overview

A Java-based implementation of the table game Galaxy Truckers developed at Politecnico di Milano. \
The team members are Francesco Canossi, Lorenzo Carafa, Tommaso Capone and Francesco Cola. \
The implementation will feature a command-line interface and a JavaFX graphical user interface.
